# 🎵 Spotify Top 50 World Dashboard

## 📌 Project Overview

This project analyzes **Spotify Top 50 World music data** to understand song rankings, artist performance, popularity, release patterns, song duration, album types, and explicit-content trends.

The project uses **Excel for data preparation** and **Power BI for interactive dashboard development**.

---

## 📊 Dataset

The dataset contains **27,800 records** and **11 columns**.

### Main Columns

| Column            | Description                                |
| ----------------- | ------------------------------------------ |
| `date`            | Date of the Spotify chart                  |
| `position`        | Song position in the chart                 |
| `song`            | Song name                                  |
| `artist`          | Artist name                                |
| `popularity`      | Spotify popularity score                   |
| `duration_ms`     | Song duration in milliseconds              |
| `album_type`      | Album, single, etc.                        |
| `total_tracks`    | Number of tracks in the album              |
| `release_date`    | Original release date                      |
| `is_explicit`     | Whether the song contains explicit content |
| `album_cover_url` | Spotify album artwork URL                  |
